# LA DOLCE VITA

Welcome to the official La Dolce Vita Italian Charm Bracelet Shop.

Since 2024, we've been celebrating personal style through customizable Italian charm bracelets.

## About the Project

This website allows customers to:
- Browse available Italian charms.
- Choose between a Plain Bracelet and "I'll Make My Own".
- Customize their own bracelet designs.
- Preview their bracelet before placing an order.
- View their selected charms and total pricing.

## Website Features

- Interactive bracelet customizer
- Silver and Gold bracelet options
- Individual charm selection
- Live bracelet preview
- Automatic price calculation
- Shopping basket
